Strategy
To document leetcode problems by section and practice different problems based on those types of problems for DSA.

key questions to ask for each problem:
- What are the inputs and expected output?
- What are the constraints and edge cases?
- What guarantees do I have?
- Is the input sorted? Are values unique? Is a solution guaranteed?
- What am I allowed to do?
- Can I modify the input? Use extra memory? Must I preserve the original order?
- What time and space complexity is required or realistic?
- Is constant space explicitly required? Would an O(n^2) approach handle the maximum input size?
