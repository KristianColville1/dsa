## Suggested Order

Work through the **Core** list first. Aim to be able to solve each problem independently and explain:

1. What data structure is being used
2. Why it is appropriate
3. Time complexity
4. Space complexity
5. Why the algorithm is correct

Then move to the Stretch problems.

The Stack/Queue Pattern problems can be left until the dedicated pattern section.
